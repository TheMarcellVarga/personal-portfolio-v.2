## Shared phase status

Use these labels inside each project plan:

- `Not started`
- `In progress`
- `Blocked`
- `Complete`
- `Deferred`
- `Not applicable`

## Shared completion rule

A phase is complete only when:

1. its code or content is implemented;
2. its verification commands pass;
3. manual checks are recorded when automation is insufficient;
4. documentation describes current behavior rather than planned behavior;
5. remaining limitations are explicit.

## Shared portfolio standard

Every featured case study must include:

- a one-sentence product outcome;
- a clear target user;
- one coherent golden path;
- actual screenshots from the implemented product;
- an architecture diagram limited to real runtime components;
- three important decisions and their trade-offs;
- loading, empty, error, and recovery behavior;
- testing and accessibility evidence;
- security and privacy boundaries;
- exact personal contribution;
- current limitations;
- a short demo video;
- repository and live demo or release link.
